LAYER 1 — THERMODYNAMIC BASE

Core Variables

E_in — available energy input

W_out — useful work performed

S_gen — entropy generated (waste, friction, loss)

R_cap — regenerative capacity of environment



---

Net Energy Balance

NEB = E_in - (W_out + S_gen)


---

Regenerative Coupling

R_cap(t+1) = R_cap(t) + η · (resource_circulation · S_gen)

Waste increases system capacity only if recaptured.

η = coupling efficiency.


---

Phase Regions (descriptive)

Phase I — Extraction
S_gen > E_in → substrate depletion

Phase II — Maintenance
NEB ≈ 0 → survival equilibrium

Phase III — Resonance
NEB > 0 → surplus emerges

Phase IV — Garden
R_cap increases → system improves substrate
